# Redy Sticker Pack V1

## Status

Stage 6 sticker pack first version is complete. The official sheet is generated as a new illustration from the Redy pose-extension direction, not cropped from the old reference sheet.

## Files

| Asset | Path |
| --- | --- |
| Sticker sheet | `brand/stickers/redy-community-sticker-pack-v1.png` |
| Animated community sticker | `brand/stickers/redy-community-sticker-animated.svg` |
| Supplemental pose PNGs | `brand/stickers/redy-sticker-01-hello.png` through `redy-sticker-08-break.png` |

## Usage

- Use the sticker sheet as the official community sticker preview.
- Use supplemental PNG files only for rough docs callouts until final individual exports are redrawn.
- Use the animated SVG for web or documentation surfaces that support SVG animation.
- Keep gestures small and warm; do not introduce loud meme-like expressions into the official pack.
