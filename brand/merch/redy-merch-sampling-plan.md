## First Sample Directions

| Item | Direction |
| --- | --- |
| Sticker pack | Six small community stickers using the Q-version Redy and Git branch accents |
| T-shirt | Small front badge plus optional branch-line back print |
| Tote bag | Warm canvas base with Redy Q-version centered |

## Production Notes

- Use warm rice, cream, rust red, soft brown, charcoal, and Git green only.
- Prefer small badge placement over oversized mascot prints for apparel.
- Keep Q-version Redy as the first merch character because it reads well at small sizes.
- Treat this as sampling kickoff, not final vendor-ready production artwork.
