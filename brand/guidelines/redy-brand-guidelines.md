# Redy 母品牌规范页初版

## 规范状态

T05 已输出母品牌规范页初版。本页用于团队在继续制作三项目图标、Badge、README 头图、官网 Hero、404 与 CLI 场景前，对 Redy 母品牌基线保持一致。

## 核心定位

Redy 是 WeOpen 的开源生态维护者、代码园丁与分支探险家。它不是单个项目的附属插画，而是 WeOpen 母品牌的人格化入口。

## 标准资产

| 类型 | 文件 | 当前用途 |
| --- | --- | --- |
| 主 Logo | `brand/logo/weopen-redy-primary.svg` | 品牌锁定、正式露出、后续 SVG 复原基准 |
| 极简头像 | `brand/logo/weopen-redy-avatar.png` | GitHub 头像、社媒头像、圆形小尺寸识别 |

| 颜色 Token | `brand/tokens/color.tokens.json` | 设计、前端与图标系统共用配色源 |

## 角色识别

- 物种：红熊猫。
- 姿态：标准立绘使用正面坐姿，安静、可靠、专注。
- 必保留特征：复古护目镜、暖棕描线、蓬松尾巴、工具腰带或轻量技术挂件。
- 技术暗示：双镜片 Git 绿代码反光、分支挂件、终端提示符只能作为局部细节，不压过角色温度。

## 配色基线

母品牌主色使用 `#C14B30`、`#F6F1E9`、`#2D2A2E`、`#2CC68E`、`#F8F5F0`、`#8B6E54`。完整 token 与项目强调色以 `brand/tokens/color.tokens.json` 和 `redy-t04-color-system.md` 为准。

## 三项目映射

| 项目 | 识别重点 | 色彩策略 |
| --- | --- | --- |
| WeMail | 信封、蜡封、收件箱、临时邮件卡片、云轮廓 | 云雾蓝灰与蜡封红棕只做局部辅助 |
| WeGit | branch graph、commit node、仓库标识、原生窗口 | 延续 Git 绿，不额外发明独立主色 |
| WeOpen | 模块卡片、控制台面板、dashboard 骨架、统一入口 | 暖灰米色与少量锈红延展，保持平台感 |

## 使用边界

- 不再使用水果符号系统映射三项目。
- Redy 不应被改成过度夸张、吵闹或纯幼态的 mascot。
- 黑色描边应替换为深炭灰或柔边棕，保持温暖手绘感。
- 技术元素必须服务于“观察、维护、筛选、协作”的叙事，不做无意义装饰。
- 三项目资产必须先保证属于同一个 WeOpen 母品牌系统，再体现项目差异。
