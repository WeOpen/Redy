# Redy PNG Export Package

## Folders

| Folder | Contents | Use |
| --- | --- | --- |
| `logo/` | Redy logo lockups and avatar PNGs | GitHub, docs, presentation, fallback assets |
| `icons/` | Product icons, badges, transparent Redy icons | README, app store-like displays, social previews |
| `mascot/` | Standard Redy and Q-version Redy | Website, 404, onboarding, stickers |
| `banners/` | WeMail, WeGit, WeOpen README headers | Repository README top visuals |
| `scenes/` | WeOpen GitHub organization header | GitHub and landing surfaces |

## Export Rules

- Use transparent PNGs for overlays or mixed backgrounds.
- Use full-background PNGs for README and GitHub surfaces where visual consistency matters more than editability.
- Keep source asset names stable so README and frontend references do not drift.
